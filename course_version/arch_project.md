## Project Description:
Game of ultimate tic-tac-toe developed in Python and implemented via a basic HTML web server. 

The board consists of 9 regular tic tac toe boards, and the user who wins 3 of the regular tic tac toe games in a line wins the game. 

The five developmental modules of the project include server api, app logic, persistence storage, html server implementation, and user information. Each developer has been assigned a specific module:

Abdelrahman-521: server api\
aatalha: html

## Game Features:
The following list is not definite and is subject to change. 

    - Game basics (start and restart game, turn taking/board status checking)
    - User information (identifier, which symbol a user wants to use "X" or "O", changing user information)
    - Save game statistics for each user (whether or not they won/lost)
    - Retrieve a user's statistics for previous/all games. 
    - HTML layout.
